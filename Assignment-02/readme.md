# GRADEBOOK ANALYZER
This mini project helps automate the entire process via a python-based gradebook analyzer CLI.
The system will read marks from input or a CSV file.

# FEATURES
1) Read and store student marks from manual input or CSV into python data structures.
2) Implement core statistical functions (mean,median,min,max).
3) Use control flow constructs to assign and summarize letter grades.
4) Apply list comprehensions for conditional filtering.
5) Format tabular output and implement a CLI loop for repeated analysis.
